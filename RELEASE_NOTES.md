# FDMfier V1 (1.0.0)

FDMfier turns solid meshes into editable FDM print previews with visible layer lines, patterned infill, and adjustable print imperfections.

- Configure layer height, wall thickness, infill, and separate top and bottom patterns. Add Standard or Tree supports, a brim, or a skirt.
- Reveal layers to inspect the interior and adjust seams, stringing, layer drift, and overhang droop.
- Orient models on the build plate, repair a copy of a mesh, and bake a preview to editable geometry. **Fuse for Translucency** joins extrusion paths to reduce internal surfaces.

Tested with Blender 5.3 on Apple Silicon Macs. Other platforms have not been tested.

## Platform testing checklist

- [x] Apple Silicon Mac
- [ ] Intel Mac
- [ ] Windows
- [ ] Linux

Download the ZIP, then use **Preferences → Add-ons → Install from Disk**. Open **FDMfier** in the 3D Viewport sidebar.
