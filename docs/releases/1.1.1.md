# FDMfier 1.1.1

FDMfier 1.1.1 changes how the preview mesh is built. Generate now joins the
walls, infill, and surfaces into a render-ready mesh, replacing the bake and
fusion steps from 1.0.10. Rounded layer lines, patterned surfaces, and infill
air gaps remain visible, with fewer internal boundaries for light to cross.

The 250-layer Gyroid Benchy generated in 118.1 seconds, down from 202.9 seconds
in an earlier 1.1.1 development build. Generation took 41.8% less time, and
the generated and evaluated meshes matched exactly.

- **Visible Layers** shows a cross-section at any print height. Narrower
  profiles help preserve thin walls near the base.
- **Imperfections** controls surface variation, stringing, and overhang sag,
  with an optional vertex-group mask.
- **Generate** uses the source’s active material. **Regenerate** keeps the preview
  material. Standard and Tree supports have a separate material slot.
- Progress appears in Blender’s status bar. Press **Esc** to cancel. Dense
  meshes can still pause briefly during final mesh creation.

## Linux x64 and Python 3.14

The Linux ZIP now includes wheels for Python 3.13 and 3.14. Thanks to
[@wonderrozz-coder](https://github.com/wonderrozz-coder) for diagnosing the
missing wheel and testing a rebuilt package on Omarchy with Blender 5.2.2 and Python
3.14.8. [Issue #1](https://github.com/nikgrv/FDMfier/issues/1)

Regenerate older previews after installing. All five ZIPs passed Blender
validation, and offline tests passed on Blender 5.3 on Apple Silicon. Native
testing of the release ZIPs on Linux, Windows, and Intel Mac is pending.
